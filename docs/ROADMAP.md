# Планы развития

Проект изначально создавался как учебный, но архитектура позволяет легко превратить его в production-решение. Ниже — приоритетные направления улучшения.

## Ближайшие задачи (high priority)

- [ ] **Миграция на TypeScript**  
    Полный переход на TS уже начат. Осталось доработать оставшиеся компоненты и утилиты.

- [ ] **Исправление логики корзины**  
    Заменить toggle-поведение `ADD_TO_BASKET` на увеличение количества:  
        - «Добавить в корзину» → `+1`  
        - «Убрать» → удалить или установить `0`  
    Это сделает поведение интуитивным и соответствующим ожиданиям пользователей.

- [ ] **Валидация email при входе**  
    Добавить простую проверку формата email в компоненте `Login`.

- [ ] **Обработка ошибок загрузки изображений**  
    Унифицировать `onError` в компоненте `CardImg` и использовать fallback-изображение.

## Среднесрочные цели (medium priority)

- [ ] **Тестирование**  
    Написать unit- и компонентные тесты с помощью Vitest и React Testing Library.

- [ ] **Улучшение оффлайн-режима**  
    Кэшировать API-ответы в `localStorage` с TTL, а не только использовать статический `data.json`.

- [ ] **Анимации и микро-интеракции**  
    Добавить плавные переходы при добавлении в корзину, переключении темы.

## Долгосрочные цели (low priority)

- [ ] **Интеграция с бэкендом**  
    Реализовать настоящую аутентификацию, сохранение корзины на сервере, историю заказов.

- [ ] **Развертывание демо-версии**  
    Опубликовать проект на Vercel или Netlify для публичного доступа.

- [ ] **Поддержка SSR/SEO**  
    Миграция на Next.js для улучшения SEO и быстрой загрузки.

## Философия проекта

> «Простота → Надёжность → Расширяемость»

Проект остаётся **минималистичным**, без избыточных зависимостей (без Bootstrap, Tailwind, сторонних UI-библиотек). Это позволяет:
- Чётко контролировать поведение
- Учиться на чистом CSS и React
- Легко вносить изменения

Любые улучшения должны соответствовать этой философии.
