# Redux-store

Проект использует **чистый Redux** (без Redux Toolkit) для управления глобальным состоянием. Весь стейт хранится в едином объекте и обновляется через иммутабельные редьюсеры.

## Структура состояния

```js
{
  likedItems: number[];                 // Массив ID избранных товаров, например: [1, 5, 12]
  basketItems: Record<string, number>;  // Объект вида { "1": 2, "5": 1 } — ключи всегда строки!
  cards: Product[];                     // Полный список товаров
  types: Category[];                    // Список категорий
}
```

> Все ключи в `basketItems` — **строки**, даже если `id` товара — число. Это критично для корректной работы `hasOwnProperty`.

## Доступные экшены

| Тип экшена | Payload | Описание |
|-----------|--------|--------|
| `RESET_APP` | — | Сбрасывает `likedItems` и `basketItems` в начальное состояние. `cards` и `types` сохраняются. |
| `SET_CARDS` | `Product[]` | Устанавливает список товаров. |
| `SET_TYPES` | `Category[]` | Устанавливает список категорий. |
| `LIKE_ITEM` | `{ id: number }` | Переключает товар в избранном: если был — удаляет, если нет — добавляет. |
| `ADD_TO_BASKET` | `{ id: number }` | **Переключает** товар в корзине: 0 ↔ 1 (используется на страницах каталога/товара). |
| `SET_BASKET_ITEM_COUNT` | `{ id: number, count: number }` | Устанавливает **точное количество** товара. Если `count <= 0` — товар удаляется из корзины (ключ удаляется из объекта). |

## Важные принципы

- **Иммутабельность**: каждый кейс в редьюсере возвращает **новый объект состояния**, даже при вложенных структурах.
- **Очистка корзины**: при `count = 0` ключ **удаляется** из `basketItems`, а не сохраняется как `0`. Это позволяет использовать `hasOwnProperty` для проверки наличия товара.
- **Синхронизация с UI**: все компоненты, зависящие от корзины/избранного, получают актуальные данные через хук `useCardsDatas`.

## Пример использования

```js
// Добавить в избранное
dispatch({ type: 'LIKE_ITEM', payload: { id: 123 } });

// Установить количество в корзине
dispatch({ type: 'SET_BASKET_ITEM_COUNT', payload: { id: 123, count: 2 } });
```

> Для страницы корзины используется `SET_BASKET_ITEM_COUNT`, а для карточек — `ADD_TO_BASKET` (toggle-логика).
