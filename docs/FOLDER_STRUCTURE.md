
# Структура проекта

Проект следует чёткой и масштабируемой структуре, основанной на функциональном разделении.

```
src/
├── assets/                     # Статические ресурсы
│   ├── media/                  # Изображения, иконки (SVG, PNG, JPG)
│   ├── fonts/                  # Шрифты
│   └── styles/                 # Reset базовых стилей и подключение шрифтов 
├── components/                 # Переиспользуемые UI-компоненты
│   ├── Card/                   # Карточка товара
│   ├── CardBtns/               # Кнопки: SaveButton, BasketButton, DeleteButton
│   ├── CardImg/                # Компонент отображения изображения товара
│   ├── Header/                 # Шапка приложения
│   ├── Navigation/             # Нижняя навигация (мобильная)
│   ├── ProfileContainer/       # Блок данных пользователя
│   ├── SearchEngine/           # Строка поиска с превью товара
│   └── SliderCardsConteiner/   # Слайдер для избранного/корзины
├── context/                    # Контексты React
│   └── SearchContext.js        # Управление состоянием поиска
├── hooks/                      # Кастомные хуки
│   ├── useCardsDatas.js        # Доступ к данным о товарах из Redux
│   └── useDarkTheme.js         # Переключение и сохранение темы
├── pages/                      # Страницы приложения (маршрутизируемые компоненты)
│   ├── Main/                   # Главная страница
│   ├── Profile/                # Профиль пользователя
│   ├── Basket/                 # Страница корзины
│   ├── Saved/                  # Избранное
│   ├── Catalog/                # Каталог товаров
│   └── ProductDetail/          # Детальная страница товара
├── store/                      # Управление глобальным состоянием
│   ├── reducer.js              # Redux-редьюсер
│   └── index.js                # создание store
├── types/                      # TypeScript-типы (только в TS-версии проекта)
│   └── api.ts                  # Интерфейсы: Product, Category, User и др. 
├── utils/                      # Вспомогательные утилиты
│   ├── generateTags.js         # Генерация тегов на карточке товара
│   ├── generateActPrice.js     # Отображение актуальной/старой цены и скидки
│   └── getItemsText.js         # Склонение слов в заголовке корзины
├── App.jsx                     # Корневой компонент: маршрутизация, провайдеры
└── main.jsx                    # Точка входа: render + импорт глобальных стилей
```

### Особенности

- **Стили**: все компоненты используют CSS Modules.
- **Глобальные стили**: подключаются в `main.jsx` и включают сброс, темы и шрифты.
- **Изоляция**: каждый компонент — в отдельной папке с собственным стилем и логикой.
- **Масштабируемость**: добавление новой страницы или компонента не нарушает структуру.
