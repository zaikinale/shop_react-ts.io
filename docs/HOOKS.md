# Кастомные хуки

Проект использует два основных кастомных хука для инкапсуляции логики и повторного использования состояния.

---

## `useCardsDatas()`

**Назначение**: централизованный доступ к данным о товарах и производным состояниям (избранное, корзина).

**Возвращает**:
```js
{
  cards: Product[],                     // Все товары
  likedItems: number[],                 // ID избранных товаров
  basketItems: Record<string, number>,  // Товары в корзине (ключ — строка!)
  typesItems: Category[],               // Все категории
  likedCards: Product[],                // Товары, отфильтрованные по `likedItems`
  basketCards: Product[]                // Товары, отфильтрованные по `basketItems`
}
```

**Где используется**:
- `Main` — для рекомендаций
- `Profile` — для отображения избранного и корзины
- `Card`, `ProductDetail`, `BasketItem` — для определения состояния кнопок

**Особенности**:
- Использует `useSelector` для получения данных из Redux
- Автоматически вычисляет `likedCards` и `basketCards` при каждом рендере
- Обеспечивает согласованность данных между компонентами

## `useDarkTheme()`

**Назначение**: управление тёмной/светлой темой с персистентностью.

**Возвращает**: `[isDark: boolean, toggleTheme: () => void]`

**Поведение**:
- При первом запуске читает тему из `localStorage`
- Если нет сохранённого значения — использует **тёмную тему по умолчанию**
- При переключении:
    - Сохраняет новое значение в `localStorage`
    - Добавляет/удаляет класс `dark-theme` на `<body>`
    - Это активирует CSS-переменные из глобальных стилей

**Где используется**:
- `Header` — кнопка переключения темы

**Пример использования**:
```js
const [isDark, toggleTheme] = useDarkTheme();

// Переключить тему
toggleTheme();

// Условный рендер
{isDark ? 'Сменить на светлую' : 'Сменить на тёмную'}
```

> Тема применяется **глобально** через CSS-переменные (`--bg`, `--tc` и др.), поэтому все компоненты автоматически адаптируются.
