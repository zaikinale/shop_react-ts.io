# Типы данных

Проект оперирует строго определёнными структурами данных. В JavaScript-версии типы задокументированы здесь; в TypeScript-версии они описаны через `interface` в `src/types/api.ts`.

## `Product`

Представляет товар в каталоге.

```js
{
    id: number;                 // Уникальный идентификатор
    name: string;               // Название товара
    price: number;              // Актуальная цена
    old_price: number | null;   // Старая цена (если есть скидка)
    images: Image[];            // Массив изображений
    marks: Mark[];              // Метки (например, "Хит", "Новинка")
}
```

## `Image`

Описывает изображение товара.

```js
{
    Image_URL?: string;         // URL изображения (альтернативное написание)
    image_url?: string;         // URL изображения
    MainImage?: boolean;        // Является ли изображение основным
    title?: string;             // Подпись (редко используется)
}
```

> В проекте используются оба поля (`Image_URL` и `image_url`) — компонент `CardImg` обрабатывает оба варианта.

## `Mark`

Метка (бейдж) на товаре.

```js
{
    Mark_Name: string;          // Текст метки, например "Хит"
    color_code: string;         // Цвет в HEX или названии, например "#FF0000"
}
```

## `Category`

Категория товаров (например, "Аксессуары", "Мыши").

```js
{
    Category_ID: number;        // Идентификатор категории
    Category_Name: string;      // Название категории
    Category_Image: string;     // Имя файла изображения категории
}
```

## `User`

Данные авторизованного пользователя (хранятся в `localStorage`).

```js
{
    email: string;              // Email пользователя
    password: string;           // Пароль (в открытом виде, учебный проект)
}
```

> **Важно**: в корзине (`basketItems`) ключи используются **в виде строк**, даже если `id` в `Product` — число.  

Это обеспечивает корректную работу `Object.prototype.hasOwnProperty.call(basketItems, String(id))`.
